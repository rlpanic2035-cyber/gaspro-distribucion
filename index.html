🔗 Conexión con Google Sheets

Cómo configurar Google Sheets

Crea un Google Sheet nuevo. En la primera hoja, nombra las columnas: fecha, camion, zona, trip, kms_ini, kms_fin, kms_rec, hora_sal, hora_ent, [productos_salida x24], [productos_retorno x24], cil_salida, cil_retorno, tasa_carga
En el Sheet, ve a Extensiones → Apps Script y pega el código de abajo.
Haz clic en Implementar → Nueva implementación → Aplicación web. Acceso: "Cualquier persona". Copia la URL generada.
Pega esa URL en el campo de arriba y presiona "Probar conexión".
CÓDIGO APPS SCRIPT:
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); var rows = data.rows; rows.forEach(function(row) { sheet.appendRow(row); }); return ContentService.createTextOutput(JSON.stringify({ok:true})) .setMimeType(ContentService.MimeType.JSON); } function doGet(e) { return ContentService.createTextOutput(JSON.stringify({ok:true,msg:"Gaspro Script activo"})) .setMimeType(ContentService.MimeType.JSON); }
